Project Title

ERR Expenses Web App with ROS API Integration

This project presents the implementation of a full-stack web application that models Ireland’s Enhanced Reporting Requirements (ERR) reporting process. The system supports expense claim recording, generation of Revenue compliant JSON submissions, and secure transmission to Revenue Online Service (ROS) system.
